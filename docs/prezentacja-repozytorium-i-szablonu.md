# RankIt
## Repozytorium i dokumenty projektu

Realizacja Projektu Informatycznego 2026/2027<br>
Repozytorium: github.com/elprofesoriqo/rpi

---

## Projekt

- Aplikacja webowa do tworzenia rankingów i oceniania różnych rzeczy.
- Proponowany pierwszy zakres: utworzenie rankingu, dodanie pozycji, oceny i uporządkowane wyniki.
- Szczegóły funkcji zostaną potwierdzone przed implementacją.

---

## Zespół

- Igor Jankowski
- Piotr Ratkowski
- Zachariasz Słupski

Zakresy odpowiedzialności proponuje raport organizacyjny. Są to zadania projektowe, nie deklaracja wcześniejszych kompetencji.

## Repozytorium

- GitHub przechowuje kod, dokumenty i historię zmian.
- `main` jest gałęzią główną; krótkie zadania pracują na gałęziach `feature/...`, `fix/...` lub `docs/...`.
- GitHub Issues zapisują zadania, a Pull Requesty pozwalają obejrzeć zmiany przed połączeniem.
- Właściciel repozytorium: `elprofesoriqo`.
